# 设计任务上下文包 · MyNAS 影视模块（桌面端 · 第一刀）

> 用法：把下面整段（从「===」开始）粘贴到设计工具里作为任务输入。它是「功能规格 + 初始指令」，不含任何旧界面外观——请大胆重做视觉，不要复刻。

===

## 你的角色与任务
你是资深产品设计师。请为一款跨平台家庭媒体客户端 **MyNAS** 重新设计**「影视」模块的桌面端（Windows/macOS/Linux）**。这是整个重设计的第一刀，目标是把它做到真正精致，并借此**确立整套产品的视觉与交互语言**。下面是功能规格——视觉风格、布局、信息层级、组件形态、动效全部由你发挥；我只约束「功能要成立」。

## 产品是什么（一句话）
不绑定品牌、**用户自带数据源**的一站式家庭媒体中枢：一个 App 里同时挂多台 NAS + 多个媒体服务器（Jellyfin/Emby/Plex）+ 下载器 + PT 站，统一访问家里所有媒体。

## 三个必须发光的「灵魂」
1. **多源并存**：影视库聚合多个数据源/媒体库，用户能切换、按源筛选，并理解内容来自哪里。
2. **端到端招牌链路**：在影视详情页一键「找资源(PT) → 发送下载器 → 自动入库 → 播放」，全程可追踪。
3. **专业播放**：字幕（含 AI 实时翻译）、多音轨、清晰度/转码、投屏、倍速、HDR/杜比。

## 全局外壳（影视处在什么环境里）
桌面端是**侧边导航栏**结构，一级入口：影视 / 音乐 / 相册 / 阅读 / 传输下载 / 连接源 / 我的（宽屏时显示文字，窄屏只显图标）。常驻元素：底部/边缘**音乐迷你播放器**、**全局搜索**、**后台长任务进度**（刮削/下载/同步）、**当前活跃源与切换入口**、投屏状态条。支持键盘快捷键切 Tab、Esc 返回、右键菜单。请在影视模块里预留这些常驻元素的落点。

## 多源的体现（影视模块必须处理）
影视内容来自两类源：① 媒体服务器（Jellyfin/Emby/Plex，已刮削好的库）；② NAS/协议源（SMB/WebDAV/群晖等，扫描本地文件后由 App 刮削）。同一个影视库会**聚合多个源/多个媒体库**。请设计：多源聚合展示、按源/库筛选、源在线/离线状态的体现。

## 需要设计的页面（影视模块 · 桌面端）

### 1. 影视首页
分区式浏览，自上而下多条横向 Rail + 库网格：
- **每日推荐 Hero**（大背景图 + 海报 + 简介 + 播放/详情按钮）
- 继续观看（带进度条的海报）
- 最近添加
- 电影库 / 剧集库（剧集按「剧」分组）
- 电影系列合集 / 其他视频
- 顶部需有：全局搜索、视图切换（网格/列表/海报墙）、源/库筛选、排序（年份/评分/添加时间/标题）、全局刮削进度条。
- 渐进加载：先出统计与首屏，再补全。

### 2. 媒体库浏览页
- Tab：全部 / 电影 / 剧集 / 其他 / 最近添加
- 网格 ↔ 列表切换；筛选 / 排序 / 搜索；多源多库切换
- 海量条目要考虑虚拟化 + 渐进加载。

### 3. 视频详情页（桌面端用左右双栏 master-detail）
- 左栏固定：海报、年份/时长/分级、**播放**、收藏、标记已看、刮削、**「PT 搜索」**、多版本（不同清晰度）选择。
- 右栏滚动：大背景图、标题/原名、**多源评分（TMDB/豆瓣/IMDb/Trakt）**、简介、演职员、**季/集选择器**（电视剧，含每集进度）、相似推荐 Rail。
- 续看：有历史时提示「从 xx:xx 继续 / 重新开始」。

### 4. 视频播放器页
- 顶栏：返回 / 标题 / 书签 / 倍速(0.5–4x)
- 中部：上一集 / 快退 / 播放暂停 / 快进 / 下一集
- 底部：进度条（缓冲、时间提示）
- **字幕菜单**（一个入口聚合）：选择字幕(内嵌/外挂/翻译轨) + 在线下载(OpenSubtitles) + 样式设置 + **AI 翻译（选目标语言，翻译中显进度）** + 关闭
- 其它弹层：音轨切换、清晰度(原始/720/1080/2K/4K，切换触发转码并显示「转码中」+进度，失败回退) + 宽高比 + 播放队列 + 书签 + **投屏设备(AirPlay/DLNA/Chromecast)**
- 投屏中：界面切换为「投屏控制态」（设备名/播放控制/音量/字幕/断开）。
- 自动下一集（可关）。

### 5. 手动刮削流程
搜索关键词 → 候选结果列表 → 预览确认（海报/简介/演职员）→ 保存入库。需有进度反馈。

## 招牌链路（在影视里埋好钩子）
详情页/推荐项点「PT 搜索」→（带「标题+年份」自动检索 PT 站）→ 种子列表（含促销标签如「免费/2x」）→ 发送下载器 → 下载中 → 自动入库 → 影视库出现新资源 → 播放。**请至少把「PT 搜索」入口和「资源状态可追踪」的概念在影视侧体现出来**（完整下载/PT 界面是后续切片）。

## 关键状态（每个列表/详情/播放器都要有）
首次无源引导 · 加载骨架 · 扫描/刮削中(x/总数) · 缓冲 · 转码中 · 无字幕 · 错误可重试 · 离线(显缓存) · 需升级会员(锁定占位非隐藏) · 需二次验证。

## 桌面端规则
信息密度高（紧凑行高/内边距）、右键菜单、拖拽、键盘快捷键、悬停态、多窗口、master-detail 双栏。鼠标精准操作，可比移动端更密。

## 视觉方向
**暗色、电影感、海报为主角**的高级媒体 App 气质（参考 Plex/Infuse 的沉浸感但要有自己的性格）；主色倾向**暗底 + 紫调强调色**。请先给 **2–3 个视觉方向**对比，选定后再深做。评分用色随分值变化（高分绿/中橙/低红）。

## 自由度边界
- **必须保留**：上面所有页面的能力都要有落点；多源可切换可筛选；招牌链路入口可见；专业播放各入口齐全；各状态都有；桌面信息密度与右键/快捷键可用。
- **完全自由**：视觉语言、配色字体图标、布局层级、卡片与列表形态、导航具体形态、手势/快捷键设计、详情页与播放器的交互重构、空态/错误/引导的表达。
- **加分探索**：统一全局聚合搜索、统一任务中心（下载/刮削/同步可视化）、资源状态像快递一样可追踪、跨端「在另一台设备继续」。

## 交付
Mockup 文案用**简体中文**。先出 2–3 个视觉方向供对比，确定后把「影视首页 + 详情页 + 播放器」做成可点的高保真，含主要状态。
